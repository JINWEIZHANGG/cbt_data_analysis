1. Introduction

This project examines whether weekly K time series display non-random temporal dynamics across participants. More specifically, the analysis focuses on short-term temporal persistence, assessed through lag-1 autocorrelation and compared with shuffled surrogate series. The aim is to determine whether the observed week-to-week fluctuations in K are stronger than would be expected by chance.

2. Data

The dataset contains weekly measurements of K for several participants. In this report, the analysis focuses on six participant-specific K variables (K1A to K6A) together with the week index (Semaine). To facilitate time-series analysis, the data are transformed from wide to long format so that each row corresponds to one participant at one measurement week.

3. Methods

The analysis begins with a visual inspection of weekly K trajectories for each participant. The main statistical analysis then evaluates lag-1 autocorrelation, which quantifies the association between a participant’s K value at a given week and the value observed in the previous week.

To test whether this week-to-week persistence is stronger than expected by chance, a surrogate analysis is performed. For each participant, K values are randomly shuffled many times to generate a null distribution of lag-1 correlations. The observed lag-1 correlation is then compared with this surrogate distribution.

Additional exploratory analyses are also included, such as autocorrelation across multiple lags and detrended fluctuation analysis (DFA), in order to examine broader temporal structure in the K time series.

# Create lagged K values within each participant and keep only consecutive weeks
# This ensures that lag-1 correlation is computed from valid week-to-week pairs
df_lag <- df_long %>%
  group_by(participant) %>%
  arrange(Semaine, .by_group = TRUE) %>%
  mutate(
    prev_week = lag(Semaine),
    K_lag1 = lag(K),
    consecutive = (Semaine - prev_week == 1)
  ) %>%
  ungroup()

The table below summarises the main lag-1 surrogate analysis for each participant. It reports the observed lag-1 autocorrelation, the surrogate-based reference interval, and the associated p-value.

# Compare observed lag-1 correlation with a null distribution obtained by randomly shuffling K values within each participant.
# If observed correlation is outside the surrogate interval, this suggests non-random temporal structure.
set.seed(123)

n_surrogates <- 1000

surrogate_results <- df_lag_valid %>%
  group_by(participant) %>%
  group_modify(~{
    observed <- cor(.x$K, .x$K_lag1, use = "complete.obs")
    
    shuffled <- replicate(n_surrogates, {
      shuffled_K <- sample(.x$K)
      cor(shuffled_K, .x$K_lag1, use = "complete.obs")
    })
    
    tibble(
      observed_acf = observed,
      shuffled_mean = mean(shuffled, na.rm = TRUE),
      shuffled_sd = sd(shuffled, na.rm = TRUE),
      lower_2.5 = quantile(shuffled, 0.025, na.rm = TRUE),
      upper_97.5 = quantile(shuffled, 0.975, na.rm = TRUE),
      p_two_sided = mean(abs(shuffled) >= abs(observed), na.rm = TRUE)
    )
  }) %>%
  ungroup()

4. Results

The participant-level time-series plots show that K varies over time and that the temporal profiles differ across individuals. The lag-1 autocorrelation analysis also suggests marked inter-individual differences in short-term persistence.

The surrogate comparison provides the main inferential result of this report. Three participants (K2A, K5A, and K6A) showed observed lag-1 correlations clearly above the upper bound of the surrogate 95% interval, suggesting stronger-than-random week-to-week persistence. In contrast, K1A, K3A, and K4A remained within the surrogate interval, indicating weaker evidence for non-random short-term temporal structure.

Beyond the lag-1 surrogate analysis, the DFA alpha values provide convergent evidence for temporal structure in several participants. Three participants showed DFA alpha values significantly above the white-noise baseline (α = 0.5): K1A (α = 0.922, p = 0.01), K2A (α = 1.03, p = 0.00), and K5A (α = 0.784, p = 0.01). Notably, K2A’s alpha value of 1.03 falls close to the theoretical pink noise reference (α = 1.0), suggesting that its K dynamics may exhibit 1/f scaling structure. This convergence is further supported by the consistency between the lag-1 and DFA results: the two participants with the highest lag-1 autocorrelations (K2A = 0.597, K6A = 0.613) also showed the two highest DFA alpha values (1.03 and 0.734, respectively), suggesting that both short-term persistence and longer-range scaling structure may co-occur in some individuals.

Beyond the main lag-1 analysis, autocorrelation across multiple lags was examined as an exploratory extension. This allows a broader description of how temporal dependence changes across increasing lag values.

As a complementary analysis, DFA was used to examine whether the weekly K series also showed broader temporal structure beyond immediate lag-1 persistence.

# DFA is included here as an exploratory complexity-oriented analysis.
# It estimates scaling behaviour in each participant's K time series.
library(nonlinearTseries)
library(tibble)
library(dplyr)

dfa_results <- df_long %>%
  group_by(participant) %>%
  group_modify(~{
    x <- .x %>%
      arrange(Semaine) %>%
      pull(K) %>%
      na.omit()
    
    dfa_obj <- dfa(
      time.series = x,
      window.size.range = c(4, floor(length(x) / 4)),
      npoints = 15,
      do.plot = FALSE
    )
    
    fit <- lm(log(dfa_obj$fluctuation.function) ~ log(dfa_obj$window.sizes))
    
    tibble(
      dfa_alpha = as.numeric(coef(fit)[2]),
      r_squared = summary(fit)$r.squared,
      n = length(x)
    )
  }) %>%
  ungroup()

The observed DFA alpha values were then compared with shuffled surrogate series in order to assess whether the apparent scaling behaviour was stronger than expected by chance.

# Compare observed DFA alpha with shuffled surrogates to assess whether the apparent scaling structure is stronger than expected by chance.
compute_dfa_alpha <- function(x) {
  x <- na.omit(x)
  
  if (length(x) < 20) return(NA_real_)
  
  dfa_obj <- dfa(
    time.series = x,
    window.size.range = c(4, floor(length(x) / 4)),
    npoints = 15,
    do.plot = FALSE
  )
  
  fit <- lm(log(dfa_obj$fluctuation.function) ~ log(dfa_obj$window.sizes))
  as.numeric(coef(fit)[2])
}

set.seed(123)
n_surrogates <- 200

surrogate_dfa <- df_long %>%
  group_by(participant) %>%
  group_modify(~{
    x <- .x %>%
      arrange(Semaine) %>%
      pull(K) %>%
      na.omit()
    
    obs_alpha <- compute_dfa_alpha(x)
    
    null_alpha <- replicate(n_surrogates, {
      x_surr <- sample(x)
      compute_dfa_alpha(x_surr)
    })
    
    tibble(
      obs_alpha = obs_alpha,
      null_mean = mean(null_alpha, na.rm = TRUE),
      lower_2.5 = quantile(null_alpha, 0.025, na.rm = TRUE),
      upper_97.5 = quantile(null_alpha, 0.975, na.rm = TRUE),
      p_upper = mean(null_alpha >= obs_alpha, na.rm = TRUE)
    )

# 5. Discussion

The present analysis provides converging evidence that weekly K dynamics are not purely random and that the degree of temporal structure varies meaningfully across participants. The surrogate-based lag-1 analysis identified three participants (K2A, K5A, K6A) with short-term persistence exceeding chance, while the DFA analysis independently flagged K1A, K2A, and K5A as showing scaling structure beyond white noise. The convergence across these two methods — and in particular the near-pink-noise alpha for K2A — suggests that motivational dynamics may, in at least some individuals, exhibit the kind of 1/f temporal organisation that has been associated with self-organised criticality and adaptive flexibility in psychological systems. These findings should nonetheless be interpreted carefully. With only six participants and series of 52–111 observations, the DFA estimates are based on limited window ranges, and the power to detect reliable scaling behaviour is modest. The results are therefore best understood as exploratory: they are consistent with a pink-noise interpretation for some participants, but do not constitute definitive evidence. Future work with longer time series and larger samples would be needed to test whether 1/f structure in motivational dynamics is robust and replicable.

6. Conclusion

This report shows that weekly K time series can be analysed with relatively simple time-series tools in R, combining visualization, lag-1 autocorrelation, surrogate testing, and DFA. The main result is that some participant-level K series appear more temporally structured than would be expected by chance, supporting the idea that motivational dynamics may contain non-random short-term persistence. Complementary DFA results further suggest that, for some participants, this temporal structure may extend beyond immediate lag-1 dependence and may be compatible with intermediate dynamics between white noise and pink noise. Given the small number of participants and the limited series length, these DFA findings should be interpreted as exploratory rather than definitive.
